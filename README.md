# FFSub 🚀

یک سرویس لبه ابری (Cloudflare Worker) سبک، مدرن و بدون‌حالت (Stateless) برای تقویت، بهینه‌سازی و تزریق خودکار تنظیمات ضد فیلترینگ و دور زدن DPI به لینک‌های سابسکریپشن (VLESS / Trojan).

---

## 💡 ایده و منابع پروژه

- **منبع تکنیک و روش دور زدن:** برگرفته از روش‌های ارائه‌شده توسط [patterniha](https://github.com/patterniha)
- **منبع ایده و الگوی ساخت:** الهام‌گرفته از پروژه [Hidden-Node/proxy-builder](https://github.com/Hidden-Node/proxy-builder)

---

## ✨ ویژگی‌ها

- 🛡️ **تزریق خودکار TLS Fragment (`fm`):** خرد کردن بسته‌های `ClientHello` برای عبور شفاف از فایروال‌ها و فیلترینگ مبتنی بر DPI.
- 🔐 **مجموعه سایفرهای بهینه (`cs`):** تنظیم خودکار بهترین و امن‌ترین Cipher Suites مدرن برای اتصالات ایمن و ناشناس‌تر.
- 🎭 **فینگرپرینت استاندارد (`fp`):** تنظیم فینگرپرینت بر روی `unsafe` برای کاهش رفتارهای شناسایی‌پذیر کلاینت‌ها.
- ⚡ **رابط کاربری مدرن و واکنش‌گرا:** طراحی شیک، تاریک و شیشه‌ای (Glassmorphism) به زبان فارسی، همراه با دکمه کپی سریع و توضیحات شفاف امنیتی.
- 🔒 **حریم خصوصی و کاملاً امن (Stateless):** هیچ سابسکریپشن، کانفیگ، توکن یا اطلاعاتی در دیتابیس ذخیره نمی‌شود و ورکر صرفاً در لحظه دریافت سابسکریپشن پارامترها را تزریق می‌کند. ترافیک اصلی دانلود/آپلود شما مستقیماً بین کلاینت و سرور خودتان رد و بدل می‌شود.

---

## 🛠️ نحوه راه‌اندازی و استفاده

### ۱. استفاده مستقیم از وب
1. آدرس ورکر خود را در مرورگر باز کنید.
2. لینک اشتراک اصلی (Subscription URL) را در کادر وارد نمایید.
3. روی دکمه **«تبدیل و ساخت لینک بهینه‌شده»** کلیک کنید.
4. لینک خروجی را در نرم‌افزارهای کلاینت مثل **V2rayNG**، **v2rayN**، **Streisand** یا **Sing-box** وارد کنید.

### ۲. استفاده از پارامتر URL
می‌توانید مستقیماً لینک خود را از طریق اندپوینت `/sub` فراخوانی کنید:
```text
https://YOUR-WORKER-DOMAIN/sub?target=https%3A%2F%2Fexample.com%2Fsub%2Ftoken
```

## 🚀 نصب و دیپلوی (Deployment)

1. کلون کردن ریپازیتوری:
   ```bash
   git clone https://github.com/mehdichamani/ffsub.git
   cd ffsub
   ```

2. نصب پیش‌نیازها:
   ```bash
   npm install
   ```

3. تست لوکال:
   ```bash
   npx wrangler dev
   ```

4. انتشار روی کلودفلر:
   ```bash
   npx wrangler deploy
   ```
